# 压测说明

## 运行方式

```bash
locust -f scripts/locust_benchmark.py --host http://localhost:8000
```

建议场景：100、500、1000 并发用户，分别持续 5 分钟。重点观察创建工单、列表查询、智能派单、数据库连接池、RabbitMQ 队列长度和 Redis 命中率。

## 目标指标

| 接口 | P95 目标 | 错误率目标 |
| --- | ---: | ---: |
| 创建工单 | < 300ms（不含真实 AI） | < 0.1% |
| 工单列表 | < 100ms | < 0.1% |
| 智能派单 | < 150ms | < 0.1% |

文档原始设计中的 QPS 数据属于设计目标，不作为本实现的实测结论。正式压测时应记录机器配置、数据量、并发模型和原始 Locust 报告，避免无条件复用示例数字。
